# Welcome to Orkestra

**Orkestra is the SaaS plumbing every product rebuilds — users, auth, RBAC, multi-tenancy, navigation, logging — already done.**

Eight core modules (`user`, `auth`, `authz`, `tenant`, `notification`, `navigation`, `logging`, `compliance`) supply the baseline on day one. Per [ADR-0006](/adrs/collapse-to-core-only-base) Orkestra is a **core-only base** — it ships no addons. A fork builds its own verticals (invoicing, payments, subscriptions, RAG, AI agents, documents, identity, …) on top, against the in-tree SDK contract, using the same `Module` seam the core is built on and toggling them at `/admin/modules`.

## Who this is for

These docs are for **operators self-hosting Orkestra** and **developers building on the SDK or contributing addons**. End-customer documentation (Tier-2 client onboarding) lives elsewhere.
