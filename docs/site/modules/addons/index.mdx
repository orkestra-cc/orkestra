# Addons

:::note Core-only base
Per [ADR-0006](/adrs/collapse-to-core-only-base) Orkestra ships **no addons** — it is a core-only base of eight modules (user, auth, authz, tenant, notification, navigation, logging, compliance). A fork adds its own optional modules in-tree; see [Adding an addon](/contributing/adding-an-addon).
:::

The verticals Orkestra used to ship were archived as **read-only snapshots** at `github.com/orkestra-cc/orkestra-addon-*`. They are not maintained and are not imported by the base — copy from them into your fork if useful (see [Customizing an archived addon](/contributing/forking-a-core-addon)).
